스프라이트 시트 분할 도구

스프라이트 시트 이미지를 가로×세로 격자로 잘라 프레임 PNG로 만들고, GIF 애니메이션을 스프라이트 시트로 변환하고, 여러 사진을 같은 크기로 일괄 자릅니다. 모든 처리는 브라우저 안에서만 이루어져 이미지 파일이 서버로 업로드되지 않습니다.

제공하는 세 가지 도구

  • 이미지 자르기 — 스프라이트 시트 이미지를 가로×세로 격자로 잘라 개별 프레임 PNG로 저장합니다. 균등 분할과 수동 경계선, 단색 배경 제거, 프레임별 개별 편집을 지원합니다.
  • GIF 스프라이트 분할 — GIF 애니메이션의 모든 프레임을 개별 PNG 모음 또는 하나의 스프라이트 시트로 변환합니다.
  • 다중 이미지 일괄 자르기 — 여러 사진을 고정한 크기로 가운데 정렬 자르고 PNG로 묶어 ZIP으로 저장합니다.

스프라이트 시트를 자르는 기본 방법

  1. 이미지 자르기 도구에서 스프라이트 시트 이미지 한 장을 선택합니다.
  2. 한 줄에 들어가는 컷 수(가로 분할)와 줄 수(세로 분할)를 입력합니다.
  3. 캔버스 아래 상태 표시줄에서 전체 크기, 1컷 크기, 총 컷 수를 확인합니다.
  4. 결과물 미리보기로 각 프레임이 제대로 잘렸는지 확인합니다.
  5. ZIP으로 저장하면 프레임 PNG와 미리보기용 index.html이 함께 묶입니다.

자세한 절차는 스프라이트 시트 분할 기본 사용법에서 단계별로 볼 수 있습니다. 여백이 끼어 있거나 프레임 크기가 제각각이라면 여백과 수동 경계선 가이드를 참고하세요.

배경 제거로 투명 PNG 만들기

스프라이트 시트 배경이 마젠타나 초록 같은 단색이라면, 배경 제거 스위치를 켜서 해당 색을 투명하게 만들 수 있습니다. 감지된 배경색과 허용 오차 슬라이더를 확인하면서 스프라이트 안쪽 색까지 지워지지 않았는지 체스판 배경으로 검증하세요. 배경 제거가 실패하는 경우와 해결 방법은 배경 제거 가이드에 정리되어 있습니다.

GIF를 스프라이트 시트로 변환하기

GIF 스프라이트 분할 도구에서는 애니메이션의 모든 프레임을 개별 PNG로 뽑거나, 가로·세로·격자 레이아웃으로 하나의 시트에 다시 배치할 수 있습니다. 배경 제거를 함께 쓰면 투명 시트로 저장됩니다. 자세한 내용은 GIF를 스프라이트 시트로 변환하기를 보세요.

자주 묻는 질문

이미지가 서버로 업로드되나요?

아닙니다. 파일 선택부터 PNG 생성, ZIP 압축까지 모든 계산이 이용자의 기기 안에서 수행됩니다. 가입이나 로그인이 필요하지 않고 비용도 없습니다.

출력 형식은 무엇인가요?

투명 영역을 유지해야 하므로 출력은 항상 RGBA PNG로 고정됩니다. JPG나 WebP를 선택하는 옵션은 없습니다.

여러 이미지를 같은 크기로 자를 수 있나요?

가능합니다. 다중 이미지 일괄 자르기 도구에서 크기와 위치를 한 번 지정하면 나머지 사진에 같은 설정이 적용됩니다. 자세한 절차는 여러 이미지 한 번에 같은 크기로 자르기에서 볼 수 있습니다.

이 도구가 하지 않는 것은 무엇인가요?

이미지 확대·축소나 리샘플링, 애니메이션 파일 생성, 색상 보정 같은 작업은 하지 않습니다. 입력 픽셀을 그대로 잘라내는 것이 이 도구의 역할입니다.
