Basics

Is this tool really free?

Yes. All features are free to use with no separate installation and no sign-up. There is no payment step and no paid plan, and because no account is created, there is never a password to enter either.

Do you upload images to a server?

No. When you select a file, the data is delivered only to the memory of the device your browser is running on, and image splitting, cutting, background removal and ZIP compression are all performed there. The processed results are not sent anywhere either, and are written to your device through your browser's download function.

That is why you never run into an upload size limit, and why you never have to expose personal photos or the game assets you are working on to anyone else. For details, please refer to the Privacy Policy.

Which file formats are supported?

Image Cutter recommends PNG and JPG, and can also open other formats the browser is able to decode. GIF Splitter is for GIF files only. In all three tools the results are saved as PNG, and there is no option to save as JPG or WebP.

Does it work on phones and tablets?

Yes, it works in both desktop and mobile browsers. Processing speed and stability do, however, depend on the performance and memory of your device. Batch Cropper handles several files at once, so it works better on a device with enough memory.

Size and limits

Are there limits on file size or number of frames?

There is no rule in the code that limits the number of frames. The practical limit is the memory of your device. In particular, entering large horizontal and vertical division counts increases both the number of frames produced and the memory used.

Only Batch Cropper has numeric limits. Width and height each accept 8 pixels or more and 20000 pixels or less, and when width multiplied by height exceeds 40 million pixels a notice appears asking you to specify a smaller size.

I have many photos that need to be the same size. Can they be done at once?

Yes. With Batch Cropper you can select several photos at once, crop them to the same size and bundle the PNGs into a ZIP. Choose one reference photo, set the size and position, and the same rule is applied to the rest.

For the detailed method, see the guide Cropping several images to one size at once.

Are there browsers that use a lot of memory?

Memory usage is determined by the total pixel count of the images being processed and by the number of frames produced. Chrome-based browsers are recommended when working with large numbers of images. If the browser feels like it is freezing during processing, close other tabs and try again.

Adjusting results

The split results keep coming out misaligned. What should I check?

In most cases it is transparent margin at the edge of the image, or irregular spacing.

  1. Set the top, bottom, left and right padding values so that only the area that actually contains content is left.
  2. Change the split mode from even split to manual adjustment and you can set each boundary directly by absolute coordinates.
  3. If it is still misaligned, adjust only that frame individually in the preview at the bottom of the screen.

You can see the detailed method in Cutting accurately with padding and manual boundaries.

The number of divisions feels too high or too low

The default division counts are 4 across and 1 down. In the status bar at the bottom of the screen you can check the total pixel size, the division area size, the size of one cut and the total number of cuts in real time. Values of 0 or less are corrected to 1, so leaving a field empty applies 1.

We have written up the method for calculating frame sizes exactly in the Pixel art image specs guide.

The background is not removed, or the character disappears too

Both cases come down to the tolerance value.

SymptomCauseWhat to do
The background is not removed at allThe background colour is not solid (noise, gradients, shadows)Raise the tolerance. The range is 0~30% for Image Cutter and 1~50% for GIF Splitter.
Part of the character disappears tooThe character colour is close to the background colour, or the tolerance is too largeLower the tolerance. If the background colour has already been detected, check the detected background colour value first.
A notice says the background colour could not be detectedThe edge of the image is not a solid colourIt works only on images whose edge is a solid colour. Try excluding the edge margin.
The edges of the result look roughThe boundary looks like a staircaseReduce the tolerance a little. Areas near the boundary are treated leniently so that some of them become transparent.

For a detailed explanation, see Creating transparent PNGs with background removal.

Can I crop only certain cuts differently and save them?

Yes. In the result preview at the bottom of the screen, click the thumbnail of a frame to enter frame editing mode, where the x, y, width and height values can be adjusted individually. To restore the original values, press the 기본값 (reset to default) button; to clear all edits at once, press 전체 초기화 (reset all). While you are editing, the 실행 취소 (undo) and 다시 실행 (redo) shortcuts work as before.

For the detailed method, see Per-frame editing and undo/redo.

Can I undo a value I changed by mistake?

Yes. In the Image Cutter screen, undo and redo remember up to 100 steps. The shortcuts are Ctrl+Z and Ctrl+Shift+Z respectively, and redo also works with Ctrl+Y. While you change values continuously they are grouped into a single step, so dragging the handle does not make the step count grow unnecessarily. Loading a new image resets the history.

Saving and results

Where are the result files saved?

Because the tool uses your browser's download function, files are saved to the location you choose. To save somewhere other than the default folder, change the path in the save dialog. Image Cutter and GIF Splitter produce a single ZIP file containing several files, and Batch Cropper also bundles several PNGs into a ZIP.

The ZIP file name includes the original file name along with the number of divisions or the crop size.

What is inside the ZIP file once I save it?

The ZIP from Image Cutter and GIF Splitter contains the cut frame PNGs together with an HTML file for previewing the animation and a background image file. Double-clicking that HTML file lets you check the animation while adjusting the playback speed slider. It works with no separate internet connection.

The ZIP from Batch Cropper contains only PNG files. For details, see Checking the animation with the ZIP and the index.html preview.

Can I organise frames into folders?

Yes. In the preview screen shown before saving, turn on 폴더 정리 (organise into folders) to create folders and place frames into them. Press and hold a thumbnail for about half a second and drop it onto a folder, or select several and press the 이동 (move) button. If you delete a folder, the files inside it return to the default location, and the remaining file numbers are renumbered consecutively.

I want to know how to turn a GIF into a sprite sheet

When you select a GIF in the GIF Splitter screen, the frame count and duration are displayed and the preview plays. Choose one of 가로 한 줄 (single row), 세로 한 줄 (single column) or 격자 (grid) under 시트 레이아웃 (sheet layout), then save in the format you want: 스프라이트 시트 (PNG) (sprite sheet PNG), 프레임 PNG 모음 (ZIP) (frames in a ZIP) or GIF 다시 저장 (re-save the GIF). If you leave 투명 영역 자동 제거 (automatic transparent area trimming) on, the transparent margin shared by all frames is trimmed away.

For the detailed method, see Converting a GIF into a sprite sheet.

When something goes wrong

A blank screen appears when I open it in my browser

This tool runs with JavaScript. Check in your browser settings that JavaScript is not disabled, then reload the page. If it is still not resolved, try opening it in a different browser.

The screen seems to freeze during processing

Processing takes a while when the image is large or when many frames are being produced. Batch Cropper shows the progress together with the current file name, and GIF Splitter stays displayed with its sliders movable while the values are recalculated. Processing continues even if you switch to another browser tab.

I have a problem that has not been resolved

Please let us know through Contact. Because this tool cannot view your images, writing down the error message shown on screen together with the browser name and version and the name of the feature where the problem occurred makes the cause far easier to identify.
