Contact details

This tool has no sign-up and no enquiry form. Simply send your message to the email address below in whatever format suits you. If you include information about the browser and device you are using, we can identify the cause much faster.

There are cases where you may need to attach an image to an enquiry. Because this tool cannot view your images, writing down the error message or status text you see on screen is actually more accurate. The information that helps us most is the browser name and version, the operating system, and the name of the feature where the problem occurred.

Please check these before writing to us

Answers to the following items are already in our frequently asked questions. If your email contains the same information, we spend less time checking it and can reply to other enquiries sooner.

  • Which image formats are supported, and what formats are the results? — Supported formats and results
  • Why do my split results look misaligned? — When the split results do not line up
  • Why is the background not removed, or why does the character disappear too? — When background removal does not work
  • Why does the page open as a blank screen in the browser? — When a blank screen is shown
  • Where are the files I saved? — Where result files are saved

Types of enquiry

  • Error report — when the tool stops working or produces an unexpected result
  • Feature request — something that does not exist yet but you would like it to
  • Documentation — when a guide's description differs from the actual screen, or is hard to understand
  • Rights — enquiries about copyright infringement, personal information or advertising

How we handle enquiries

  1. We check the emails you send in order.
  2. If we can identify the cause we reply straight away, and if confirmation takes longer we report on progress in the meantime.
  3. When a bug needs fixing, we update the explanations in the feature guides and the FAQ together, so that the same question is not asked again.

Try the tool itself

It helps to run it yourself before writing to us. You can start using it straight away, with no sign-up.
