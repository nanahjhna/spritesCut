여백과 수동 경계선으로 정확히 나누기

격자가 깔끔하면 균등 분할 한 번으로 끝나지만, 실제 받아온 시트는 제멋대로인 경우가 많습니다. 프레임 사이에 투명 틈이 있고 마지막 줄이 반만 차 있고, 프레임마다 폭이 다릅니다. 이럴 때 쓰는 두 가지 도구, 영역 여백과 수동 경계선을 정리했습니다.

균등 분할이 통하지 않는 세 가지 경우

먼저 문제가 어디에서 생기는지 구분해 두면 해법이 바로 정해집니다.

프레임 사이에 투명 여백이 있는 경우

자동 생성 도구나 편집 프로그램에서 프레임을 내보낼 때, 프레임마다 투명한 테두리가 붙는 경우가 많습니다. 시트가 512 × 128인데 실제 스프라이트가 32 × 32 네 개가 좌우 32px 간격으로 놓여 있다면, 4등분한 결과인 128 × 128 컷에는 스프라이트가 한쪽에 붙고 나머지는 투명해집니다. 애니메이션에서는 스프라이트가 제자리에서 미세하게 흔들리는 것처럼 보입니다.

마지막 줄이 부분적으로만 채워진 경우

9프레임이 4 × 4 격자에 들어 있는 시트를 4등분하면 마지막 줄은 반만 차고 나머지 한 컷은 완전한 투명 영역이 됩니다. 출력 파일 개수만 늘어날 뿐 쓸 수 있는 결과는 나오지 않습니다.

프레임 폭이 서로 다른 경우

관공별로 폭이 다른 이미지나, 정사각이 아닌 종횡비로 그려진 파트로가 섞인 시트가 그렇습니다. 어느 값을 넣어도 오차가 생기고, 오차가 컷마다 달라 애니메이션이 출렁거립니다.

핵심 여백 문제는 영역 여백으로, 폭이 다른 문제는 수동 조절 모드로 풉니다. 두 기능은 함께 쓸 수 있고, 수동 모드에서도 영역 여백은 그대로 적용됩니다. 순서로는 먼저 여백으로 바깥쪽 투명 영역을 걷어 낸 뒤, 남은 영역 안에서 경계선을 조정하는 편이 좌표를 외우기 쉽습니다.

1단계. 이미지를 올리고 어긋난 곳 찾기

스프라이트 시트 도구의 이미지 자르기에서 이미지를 선택합니다. 캔버스는 이미지를 100% 크기로 띄우고, 투명 영역에는 체스판 패턴이 깔립니다. 가이드 상자 바깥은 어두워지고, 내부에는 격자선과 컷마다 순번이 붙은 작은 표시가 그려집니다. 순번 표시는 나중에 결과물의 몇 번 컷에 대응하는지 알려 주므로, 지금 잘못 나온 위치를 눈으로 확인해 두면 이후 수정과 대조하기 편합니다.

2단계. 영역 여백으로 바깥 여백 걷어내기

분할 모드가 균등 분할일 때 영역 여백 항목에 네 개의 칸이 나타납니다. "영역 여백 (상단 / 하단)" 그룹에는 상단 여백과 하단 여백, "영역 여백 (좌측 / 우측)" 그룹에는 좌측 여백과 우측 여백이 있습니다. 단위는 px입니다.

숫자를 입력하면 즉시 반영되고, 같은 위치를 캔버스의 드래그 핸들로 끌어당겨도 값이 바뀝니다. 익숙한 쪽을 고르세요. 숫자 입력은 정밀하고, 핸들은 눈대중으로 영역을 줄일 때 빠릅니다. 핸들로 먼저 대략 좁힌 다음 숫자로 마무리하는 순서가 효율적입니다.

예를 들어 512 × 128 시트에 32 × 32 프레임이 32px 간격으로 놓여 있다면 좌우 여백을 각각 16px, 여백 값 반영 후 영역 폭은 512 − 32 = 480px가 되고, 4등분하면 한 컷은 정확히 120 × 128이 아니라 계산된 간격에 맞춰 떨어집니다. 잘라서 미리보기에서 확인하면서 값을 조정하면 됩니다.

3단계. 분할 모드를 수동 조절로 바꾸기

분할 모드 세그먼트에서 수동 조절을 선택합니다. 모드가 바뀌면 경계선 입력 영역이 나타납니다. 앞의 여백 설정은 그대로 살아 있으므로, 먼저 2단계를 끝내고 넘어오면 좌표 계산이 편합니다.

4단계. 경계선 좌표 직접 입력하기

수동 모드에서는 경계선을 좌표로 지정합니다. 두 그룹의 도움말을 그대로 옮겨 적으면 이렇습니다.

"가로 경계선 위치 (px)" — 세로선 1개당 절대 좌표 • 0 ~ 이미지 폭, "세로 경계선 위치 (px)" — 가로선 1개당 절대 좌표 • 0 ~ 이미지 높이.

즉 가로 경계 N은 세로 방향으로 그어지는 세로선의 x 좌표이고, 세로 경계 N은 가로 방향으로 그어지는 가로선의 y 좌표입니다. 첫 경계선과 이미지 왼쪽(또는 위쪽) 사이, 이웃한 두 경계선 사이, 마지막 경계선과 이미지 오른쪽(또는 아래쪽) 사이가 각각 하나의 컷이 됩니다. 경계선이 하나 줄면 총 컷 수 하나가 줄어듭니다.

값은 원본 이미지 기준의 절대 픽셀 좌표입니다. 캔버스를 브라우저로 확대해서 보고 있더라도 입력하는 숫자는 확대된 화면의 좌표가 아니라 이미지 좌표입니다.

5단계. 경계선이 맞물리는 규칙

좌표를 자유롭게 넣을 수 있지만, 결과가 깨지지 않도록 제약이 걸려 있습니다. 경계선은 이웃 경계선보다 최소 10px 떨어진 곳까지만 이동합니다. 이웃보다 안쪽으로 들어가려 하면 그 자리에서 멈추므로, 폭이 아주 좁은 컷을 만들려고 값을 밀어 넣어도 잘리지 않습니다. 첫 경계선과 마지막 경계선은 이미지 범위를 벗어날 수 없습니다.

이 제약은 실수로 컷이 사라지거나 뒤집히는 것을 막아 줍니다. 다만 원하는 프레임 폭이 10px보다 작다면 수동 경계선으로는 만들 수 없다는 뜻이니, 그런 경우에는 원본 시트의 스케일이나 레이아웃을 바꿔야 합니다. 상태 표시줄의 1컷 크기에서 최솟값을 확인하면 이것을 바로 알 수 있습니다.

6단계. 상태 표시줄로 검증하고 저장하기

수동 모드에서는 상태 표시줄에 "수동 조절" 표시가 붙고, 1컷 크기가 최솟값~최댓값 범위로 표시됩니다. 폭이 다른 프레임을 다루면 이 범위가 두 값 이상으로 벌어지는데, 의도한 크기인지 확인하는 가장 빠른 방법입니다. 전체 크기, 영역 크기(상·하·좌·우), 총 컷 수(C×R)는 균등 모드와 동일하게 계속 보입니다.

검증이 끝나면 결과물 미리보기에서 각 컷을 확인합니다. 썸네일에 붙는 라벨의 크기가 상태 표시줄의 범위와 맞는지 대조하면 실수를 빨리 잡습니다.

경계선 위치는 편집할 때마다 실행 취소 기록에 쌓입니다. 여러 값을 시도했다가 이전 상태로 되돌리고 싶다면 Ctrl+Z를 누릅니다. 되돌리는 과정에서 잘못된 값이 섞여 들어오면 "균등 간격으로 초기화" 버튼을 눌러 경계선을 다시 고르게 배치된 상태에서 시작할 수 있습니다. 버튼을 누르면 현재 영역 안에서 경계선이 균등하게 다시 배치됩니다.

여백과 수동 조절을 함께 쓰는 순서

두 기능을 섞어 쓸 때는 순서가 중요합니다. 다음 흐름이 가장 안정적입니다.

  1. 이미지를 불러오고 균등 분할 모드에서 영역 여백 4방향으로 투명 바깥 여백을 걷어냅니다.
  2. 상태 표시줄의 영역 크기를 확인해 남은 영역이 의도한 크기인지 봅니다.
  3. 분할 모드를 수동 조절로 바꾸고 경계선 개수에 맞는 값들을 입력합니다.
  4. 상태 표시줄의 "수동 조절" 표시와 1컷 크기 범위를 확인합니다.
  5. 결과물 미리보기에서 각 컷을 보고,개별적으로 어긋난 컷이 있으면 프레임 편집으로 보정합니다.
  6. 저장 및 다운로드 (ZIP) → 미리보기 대화상자에서 최종 확인 후 다운로드 (ZIP).

5단계에서 개별 컷을 손보아야 한다면 프레임 개별 편집과 실행 취소 가이드를, 파일을 내보낸 뒤 재생 결과를 확인하고 싶다면 ZIP과 index.html 미리보기 가이드를 이어서 보세요. 배경이 단색이라 투명 PNG가 필요하다면 배경 제거 가이드가 맞습니다.
