기능 사용 가이드

스프라이트 시트 분할 도구의 세 가지 도구를 실제로 다루는 방법을 단계별로 정리했습니다. 처음이라면 1번부터 순서대로 읽으시면 전체 흐름을 파악할 수 있습니다.

먼저 알아 두면 좋은 것

이 도구는 브라우저에서만 동작합니다. 설치할 프로그램이 없고 회원가입도 필요 없습니다. 선택한 이미지와 GIF는 서버로 전송되지 않고, 브라우저가 실행 중인 기기 안에서만 디코딩·분할·압축됩니다. 저장할 파일은 브라우저의 다운로드 기능으로 직접 기기에 기록됩니다.

제공하는 세 가지 도구

  • 이미지 자르기

    스프라이트 시트 이미지를 가로×세로 격자로 잘라 프레임 PNG로 저장합니다. 균등 분할과 수동 경계선, 단색 배경 제거, 프레임별 개별 편집을 지원합니다.

    도구 열기

  • GIF 스프라이트 분할

    GIF 애니메이션의 모든 프레임을 개별 PNG 모음 또는 하나의 스프라이트 시트로 변환합니다. 투명 영역 자동 제거와 단색 배경 제거를 함께 쓸 수 있습니다.

    도구 열기

  • 다중 이미지 일괄 자르기

    여러 사진을 고정한 크기로 가운데 정렬 자르고 PNG로 묶어 ZIP으로 저장합니다. 크기·위치를 한 번에 지정하면 나머지 사진에는 같은 설정이 적용됩니다.

    도구 열기

가이드 전체 목록

  1. 1. 스프라이트 시트란 무엇인가? 기초 개념 정리

    프레임 크기를 계산하는 방법, 행 우선·열 우선 배치 차이, 투명 배경과 단색 배경의 차이 등 분할 전에 알아야 할 기초 개념을 정리합니다.

  2. 2. 스프라이트 시트 분할 기본 사용법

    이미지를 불러오고 가로·세로 분할 수를 입력한 뒤 미리보기로 확인하고 ZIP으로 저장하는 기본 흐름을 다룹니다.

  3. 3. 여백과 수동 경계선으로 정확히 나누기

    균등 격자로 맞지 않는 시트에서 남는 투명 여백을 걷어내고, 절대 좌표로 경계선을 직접 지정하는 방법을 설명합니다.

  4. 4. 배경 제거로 투명 PNG 만들기

    단색 배경을 자동으로 감지해 투명하게 바꾸는 기능과, 허용 오차 값을 상황별로 맞추는 방법을 다룹니다.

  5. 5. 프레임 개별 편집과 실행 취소/다시 실행

    특정 컷만 크기나 위치를 바꾸는 방법과, 실수로 바꾼 값을 되돌리는 실행 취소·다시 실행 단축키를 정리합니다.

  6. 6. ZIP과 index.html 미리보기로 애니메이션 확인

    저장되는 ZIP 안의 구성 요소와, 폴더로 프레임을 정리한 뒤 애니메이션을 미리 확인하는 방법을 설명합니다.

  7. 7. GIF를 스프라이트 시트로 변환하기

    GIF를 고른 뒤 시트 레이아웃과 배경 처리 옵션을 정하고, 세 가지 저장 방식 중 무엇을 골라야 하는지 안내합니다.

  8. 8. 여러 이미지 한 번에 같은 크기로 자르기

    사진 여러 장을 한 번에 골라 동일 크기로 자르고 ZIP으로 묶는 방법과, 기준 사진이 필요 있는 이유를 다룹니다.

  9. 9. 픽셀 아트 이미지 규격 가이드

    확대하지 말아야 하는 이유, 프레임 크기와 용량 계산, 내보내기 전 점검 항목을 정리합니다.
