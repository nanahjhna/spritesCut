프레임 개별 편집과 실행 취소/다시 실행

컷 대부분은 잘린 상태가 맞는데 몇 개만 위치가 어긋났다면 전체 설정을 다시 만지실 필요가 없습니다. 결과물 미리보기에서 한 프레임만 골라 고치고, 실수로 망가뜨렸을 때는 단축키 한 번으로 되돌리면 됩니다.

왜 프레임을 따로 고쳐야 하는가

분할 결과를 뒤늦게 확인하다 보면 두 가지 문제가 나옵니다. 하나는 잘못 나온 프레임이 몇 개 있는 경우입니다. 여백이 조금 어긋났거나, 마지막 줄이 부분적으로 차 있어 특정 컷에 투명 영역이 많이 남는 경우입니다. 다른 하나는 같은 프레임 안에서 일부만 잘린 경우입니다. 외곽선이 한 픽셀씩 끊기거나, 정면에 선 캐릭터의 너머에 배경이 함께 딸려 들어온 경우입니다.

이런 문제를 분할 수 자체를 다시 계산해 해결하려 하면 여백 값까지 연쇄적으로 바뀌어 오히려 더 꼬입니다. 개별 편집은 이런 상황을 위해 만들어진 기능입니다. 전체 격자는 그대로 둔 채 대상 프레임 한 장의 좌표와 크기만 덮어씁니다.

중요 개별 편집 값은 해당 분할 수 기준으로만 적용됩니다. 가로·세로 분할 수를 바꾸면 프레임의 개수와 위치 자체가 달라지므로 개별 조정은 초기화됩니다. 분할 수를 여러 조합으로 시험할 계획이라면, 각 조합의 편집을 따로 유지할 수는 없고 완성된 시트에 한 번씩 조정해야 합니다.

1단계. 결과물 미리보기 펼치기

스프라이트 시트 도구의 이미지 자르기를 열고 이미지를 불러온 뒤, 화면 하단의 결과물 미리보기 패널을 펼칩니다. 이 패널은 접었다 펼 수 있어서, 분할 수를 시험할 때는 접어 두고 결과가 나왔을 때만 열어 보는 편이 편합니다.

패널이 열리면 투명 영역을 보여 주는 체스판 배경 위에 썸네일 격자가 나타납니다. 헤더에는 총 컷 수인 "{n}컷"이 표시되고, 개별 조정이 하나라도 들어 있으면 전체 초기화 버튼이 함께 나타납니다. 이 버튼이 보인다는 것은 "이 시트에 수동으로 손댄 프레임이 있다"라는 뜻이므로, 설정을 처음부터 다시 확인하고 싶을 때 유용합니다.

2단계. 썸네일 라벨 읽기

각 썸네일에는 "순번 · 가로×세로" 형태의 라벨이 붙습니다. 7 · 128×128처럼 보인다면 결과물의 7번 컷이 128 × 128이라는 뜻입니다. 썸네일 크기는 화면에 맞추기 위해 축소되지만, 라벨의 숫자는 실제 픽셀 값 그대로입니다. 그래서 살피기만 해도 어느 프레임이 크기가 다른지 한눈에 드러납니다.

체스판 배경을 함께 보세요. 배경색이 많이 남아 있는 프레임과 깨끗하게 투명해진 프레임이 나란히 있으면, 투명 처리 문제를 어느 구간에서 지목을 해야 하는지도 알 수 있습니다.

3단계. 프레임 편집 모드 진입하기

고칠 프레임의 썸네일을 누르면 "프레임 N 편집" 모드로 들어갑니다. 이때 캔버스가 동시에 바뀝니다.

  • 전체 격자 대신 선택한 프레임 하나만 핸들로 잡힙니다.
  • 가이드 상자 바깥을 어둡게 처리하던 채도 해제가 꺼집니다. 원본 전체를 같은 밝기로 볼 수 있어서 주변 프레임과 위치를 대조하기 좋습니다.
  • 핸들을 끌면 선택 프레임의 좌표와 크기가 바로 바뀝니다.

여러 프레임을 하나씩 확인해야 할 때는 편집 모드로 들어갔다가 편집 종료를 눌러 나온 뒤 다음 썸네일을 누르는 방식으로 반복하면 됩니다.

4단계. x, y, w, h 값 바꾸기

편집 화면에는 x, y, w, h 네 개의 입력 칸이 있습니다. x와 y는 원본 이미지 기준 좌표, w와 h는 잘라낼 영역의 너비와 높이입니다. 핸들로 끌든 숫자를 입력하든 결과는 같습니다.

여기에 두 가지 규칙이 있습니다. 프레임의 최소 크기는 8 × 8 px입니다. 이보다 작게 만들려는 입력은 받아들여지지 않으므로, 원본 해상도가 부족한 경우에는 시트를 확대해 만드는 수밖에 없습니다. 그리고 값이 바뀌면 약 150ms 정도의 지연 후 미리보기와 결과가 다시 계산됩니다. 여러 칸을 연달아 입력할 때는 마지막 입력만 반영되는 것처럼 보일 수 있는데, 잠시 기다린 뒤 확인하면 정상입니다.

좌표는 이미지 픽셀 단위의 정수로 다룹니다. 브라우저 확대 상태와 상관없이 이미지 좌표를 입력한다는 점을 다시 한 번 기억해 두세요.

5단계. 기본값 복원과 전체 초기화

수정을 되돌리는 방법은 두 가지입니다.

기본값은 현재 편집 중인 프레임 하나만 분할 수 기준으로 되돌립니다. 다른 프레임의 조정은 그대로 유지되므로, 여러 프레임을 손보다가 하나만 잘못했을 때 유용합니다.

전체 초기화는 모든 프레임의 개별 조정을 한 번에 지웁니다. 앞서 경계선이나 여백을 손볼 때처럼 많은 값을 시도해 놓은 뒤 초기 상태로 돌아가고 싶을 때 씁니다. 이 버튼은 개별 조정이 하나라도 있을 때만 나타납니다.

또한 프레임 편집 모드에서 나갈 때는 편집 종료를 누릅니다. 이때 개별 조정 값은 그대로 유지되어 저장에 반영됩니다.

6단계. 실행 취소와 다시 실행

경계선 이동, 여백 변경, 프레임 편집처럼 값을 바꾸는 동작은 모두 기록됩니다. 기록은 최대 100단계까지 유지됩니다. 그리고 같은 대상에 대한 연속 조작은 0.35초 안에 이어질 경우 한 단계로 합쳐집니다.

이 병합 규칙이 실용적인 이유는 명확합니다. 핸들을 한 번 드래그하는 동안 값이 60번 바뀔 수 있습니다. 매번 기록하면 실행 취소 한 번으로는 드래그 이전 상태로 돌아갈 수 없고 60번을 눌러야 했을 것입니다. 병합 덕분에 한 번의 드래그가 한 단계로 남아, 한 번 눌러 드래그 전 상태로 정확히 되돌아갑니다.

단축키는 다음과 같습니다.

이미지 자르기 도구 단축키
단축키동작설명
Ctrl + Z실행 취소직전 변경 상태로 되돌림
Ctrl + Shift + Z다시 실행되돌린 변경을 다시 적용
Ctrl + Y다시 실행Ctrl + Shift + Z와 같은 동작
Ctrl + S저장다중 이미지 일괄 자르기에서 ZIP 저장

또한 새로운 이미지를 불러오면 기록은 통째로 초기화됩니다. 이미지 자체가 바뀌었으므로 이전 이미지의 상태로 되돌릴 이유가 없기 때문입니다. 반대로 파일을 다시 선택하지 않고 경계선을 계속 조작하는 동안에는 기록이 누적되므로, 실험을 마친 뒤 확실히 초기화하고 싶으면 이미지를 다시 불러오는 방법도 있습니다.

실전 정리

여러 값을 만지작거리게 되는 작업을 할 때는 다음 흐름이 안전합니다.

  1. 분할 수를 정하고 상태 표시줄에서 총 컷 수와 1컷 크기를 확인합니다.
  2. 결과물 미리보기를 열어 라벨이 전부 같은 크기인지 훑어봅니다.
  3. 다른 크기인 썸네일만 하나씩 열어 좌표와 크기를 조정합니다.
  4. 실수로 전체를 망가뜨렸다면 Ctrl+Z를 누르거나, 과하게 손댄 상태라면 전체 초기화를 누릅니다.
  5. 편집 종료를 누른 뒤 저장 및 다운로드 (ZIP) → 미리보기 대화상자에서 최종 확인.

확정된 프레임들을 실제로 재생해 보고 싶다면 ZIP과 index.html 미리보기 가이드를 참고하세요. 그리고 프레임이 GIF 이미지에 들어 있다면 GIF 분할 가이드가 이어지는 단계입니다.
