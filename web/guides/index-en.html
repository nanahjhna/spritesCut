What you need to know first

This tool runs entirely in your browser. There is nothing to install and no account to create. The images and GIFs you pick are never sent to a server: they are decoded, split and compressed inside the browser on the device you are using. Files are written straight to your device through the browser's own download mechanism.

The three tools

  • Image Cutter

    Cuts a sprite sheet image into a horizontal × vertical grid and saves each frame as a PNG. Supports equal grid cutting, manual boundaries, solid background removal and per-frame editing.

    Open the tool

  • GIF Splitter

    Turns every frame of a GIF animation into either a set of individual PNG files or a single sprite sheet. Automatic transparent-area trimming and solid background removal are available.

    Open the tool

  • Batch Cropper

    Crops many photos to one fixed size with centre alignment and bundles the results into a ZIP of PNG files. Set the size and position once and every other photo follows the same rule.

    Open the tool
