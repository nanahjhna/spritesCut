About

The Sprite Sheet Splitter is a free tool that lets you tidy up the image assets you use in games and on the web, right inside your browser. This page explains what it makes and why it was made.

What this tool does

In game development and web work, it is common to collect the many scenes (frames) in which a character moves into one large image, that is, a sprite sheet. Conversely, there are moments when one large sheet image has to be cut back into individual frames. This tool does exactly that job.

Put simply, this tool does three things for you.

  • It cuts one sprite sheet into multiple frame images.
  • It converts a GIF animation into per-frame images or into a single sprite sheet.
  • It crops several photos to the same size and bundles them into one ZIP file.

These jobs originally required Photoshop or a separate program to be installed. What was actually needed, though, was only one thing: "cut it and save it as a file". Launching a heavy editor for that single task was an unreasonable burden, so we made this tool.

Why it runs only in the browser

The most important design goal of this tool is that images are not sent to a server. Since all image decoding, cutting, background removal and ZIP compression run inside your browser, the following all hold true.

  • There is nothing to upload, and no time spent uploading.
  • You never run into an upload size limit.
  • You never have to expose personal photos or the game assets you are working on to anyone else.
  • It runs immediately in any computer's browser, with nothing to install.

The processed results are not sent anywhere either. Result files are written directly to your own device through the browser's download function. For details, please refer to the Privacy Policy.

Feature set

Image Cutter

This is the feature you will use most often. After loading a sprite sheet image, you specify the number of horizontal and vertical divisions, and each frame is separated as a PNG. It offers both an even grid division and a method that marks irregular gaps or unwanted margins at the edges of the image as manual boundaries.

If the image has a solid colour background, it can detect the background automatically and make it transparent. If you are not happy with the split result, you can adjust the size or position of a particular frame again, or undo your changes. Saving is done in one ZIP file, and inside it you will find the frame PNGs together with an HTML file for previewing the animation and the background image.

See the basic usage · See how to remove backgrounds

GIF Splitter

A GIF stores many frames compressed into a single file. This tool splits a GIF into individual PNGs, one per frame, or builds a single sprite sheet with the frames laid out in a single row, a single column, or a grid. It automatically trims the transparent margins around the GIF and, if the background is a solid colour, removes it before saving.

See the GIF conversion guide

Batch Cropper

Use this when you need to make many photos the same size at once. Choose one photo as the reference, set the size and position you want, and the same rule is applied to all the others. The results are all converted to PNGs of the same pixel size and placed into a single ZIP.

See the batch cropping guide

An honest description of the technical approach

All image processing in this tool is done with deterministic, pixel-by-pixel operations. For example, the background removal feature samples the colours along the edge of the image to find a representative colour, then calculates the distance between each pixel and that colour and makes the pixel transparent (alpha 0) when the distance is within a set range. The same input always produces the same output.

For the same reason, this tool cannot be applied to any kind of creative work in the general sense. It does not learn from and redraw pictures in a particular style, and it does not offer such a feature.

Cost and how to use it

This tool can be used with no separate installation and no sign-up, and every feature is free to use. There is no payment step and no paid plan. Because no account is created, there is never a password to enter either.
