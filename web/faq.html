기본 사항

이 도구는 정말 무료인가요?

네. 별도의 설치나 회원가입 없이 모든 기능을 무료로 사용할 수 있습니다. 결제 단계나 유료 플랜이 없고, 계정을 만들지 않기 때문에 비밀번호를 입력할 일도 없습니다.

이미지를 서버에 업로드하나요?

업로드하지 않습니다. 파일을 선택하면 데이터는 브라우저가 실행 중인 기기의 메모리로만 전달되고, 이미지 분할·자르기·배경 제거·ZIP 압축이 모두 그 안에서 수행됩니다. 처리된 결과 역시 외부로 전송되지 않으며 브라우저의 다운로드 기능으로 기기에 기록됩니다.

이 때문에 업로드 용량 제한에 걸리지 않고, 개인 사진이나 작업 중인 게임 자산을 외부에 노출할 필요가 없습니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.

어떤 파일 형식을 지원하나요?

이미지 자르기는 PNG와 JPG를 권장하며 브라우저가 해독할 수 있는 그 밖의 형식도 열 수 있습니다. GIF 스프라이트 분할은 GIF 파일 전용입니다. 결과물은 세 가지 도구 모두 PNG로 저장되며, JPG나 WebP로 저장하는 옵션은 없습니다.

휴대폰이나 태블릿에서도 동작하나요?

네, 데스크톱과 모바일 브라우저 모두에서 동작합니다. 다만 처리 속도와 안정성은 기기의 성능과 메모리에 따라 달라집니다. 다중 이미지 일괄 자르기는 여러 파일을 한 번에 다루므로 메모리가 충분한 기기에서 사용하는 편이 좋습니다.

용량과 제한

파일 용량이나 프레임 수에 제한이 있나요?

프레임 개수를 제한하는 규칙은 코드에 없습니다. 실질적인 한계는 기기의 메모리입니다. 특히 가로와 세로의 분할 수를 크게 입력하면 만들어지는 프레임 수와 메모리 사용량이 함께 늘어납니다.

다중 이미지 일괄 자르기에만 수치 제한이 있습니다. 가로와 세로는 각각 8픽셀 이상 20000픽셀 이하이며, 가로와 세로를 곱한 값이 4000만 픽셀을 넘으면 더 작은 크기를 지정하라는 안내가 표시됩니다.

같은 크기로 만들어야 하는 사진이 많습니다. 한 번에 처리할 수 있나요?

네. 다중 이미지 일괄 자르기를 사용하면 사진 여러 장을 한 번에 골라 같은 크기로 자르고 PNG를 ZIP으로 묶을 수 있습니다. 기준이 될 사진 한 장을 정하고 크기와 위치를 지정하면 나머지에도 같은 규칙이 적용됩니다.

자세한 방법은 여러 이미지 한 번에 같은 크기로 자르기 가이드를 참고해 주세요.

메모리를 많이 쓰는 브라우저가 있나요?

처리할 이미지의 전체 픽셀 수와 만들어지는 프레임 수에 따라 메모리 사용량이 결정됩니다. 대량의 이미지를 다룰 때는 Chrome 계열 브라우저를 권장합니다. 처리 중 브라우저가 멈추는 느낌이 들면 다른 탭을 닫고 다시 시도해 보세요.

결과 조정

분할 결과가 자꾸 어긋나는데 무엇을 확인해야 하나요?

대부분 이미지 가장자리의 투명 여백이나 규칙적이지 않은 간격 때문입니다.

  1. 상단·하단·좌측·우측 여백 값을 지정해 실제로 콘텐츠가 있는 영역만 남겨 보세요.
  2. 분할 모드를 균등 분할에서 수동 조절로 바꾸면 각 경계선을 절대 좌표로 직접 지정할 수 있습니다.
  3. 여전히 어긋난다면 하단 미리보기에서 해당 프레임만 개별 조정하세요.

자세한 방법은 여백과 수동 경계선으로 정확히 나누기에서 볼 수 있습니다.

분할 수가 너무 많거나 적다고 느껴요

가로와 세로 분할 수는 기본값이 가로 4칸, 세로 1칸입니다. 화면 하단의 상태 표시줄에서 전체 픽셀 크기, 분할 영역 크기, 한 컷의 크기, 총 컷 수를 실시간으로 확인할 수 있습니다. 입력값이 0 이하이면 1로 보정되므로 빈칸으로 두면 1이 적용됩니다.

프레임 크기를 정확히 계산하는 방법은 픽셀 아트 이미지 규격 가이드에 정리해 두었습니다.

배경 제거가 되지 않거나 캐릭터까지 사라집니다

두 경우 모두 허용 오차 값과 관련되어 있습니다.

겪치는 증상원인조치
배경이 전혀 없어지지 않음배경색이 단색이 아님(노이즈, 그라데이션, 그림자)오차를 올려 보세요. 이미지 자르기는 0~30%, GIF 분할은 1~50% 범위입니다.
캐릭터 일부가 함께 사라짐캐릭터 색이 배경색과 가깝거나 오차가 너무 큼오차를 내리세요. 이미 배경색이 감지되었다면 감지된 배경색 값을 먼저 확인해 보세요.
배경색을 감지하지 못했다는 안내이미지 가장자리가 단색이 아님가장자리가 단색인 이미지에서만 동작합니다. 가장자리 여백을 제외해 보세요.
결과 가장자리가 거칠게 보임경계선이 계단처럼 보임오차를 조금 줄여 보세요. 경계 근처는 일부 투명해지도록 완화 처리됩니다.

자세한 설명은 배경 제거로 투명 PNG 만들기를 참고해 주세요.

특정 컷만 다르게 잘라서 저장할 수 있나요?

가능합니다. 화면 하단의 결과물 미리보기에서 해당 프레임의 썸네일을 누르면 프레임 편집 모드로 들어가고, x·y·가로·세로 값을 개별 조정할 수 있습니다. 원래대로 돌리려면 기본값 버튼을 누르고, 모든 수정을 한꺼번에 지우려면 전체 초기화를 누릅니다. 편집 중에는 실행 취소와 다시 실행 단축키도 그대로 동작합니다.

자세한 방법은 프레임 개별 편집과 실행 취소/다시 실행을 참고해 주세요.

잘못 바꾼 값을 되돌릴 수 있나요?

가능합니다. 이미지 자르기 화면에서는 실행 취소와 다시 실행이 최대 100단계까지 기억됩니다. 단축키는 각각 Ctrl+Z와 Ctrl+Shift+Z이며, 다시 실행은 Ctrl+Y로도 동작합니다. 연속으로 값을 바꾸는 동안에는 하나의 단계로 묶어 처리되므로 손잡이를 드래그해도 단계가 계속 늘어나지 않습니다. 새 이미지를 불러오면 기록은 초기화됩니다.

저장과 결과물

결과 파일은 어디에 저장되나요?

브라우저의 다운로드 기능을 사용하므로 이용자가 지정한 위치에 저장됩니다. 기본 폴더가 아닌 다른 곳에 저장하려면 저장 대화상장에서 경로를 바꾸면 됩니다. 이미지 자르기와 GIF 분할은 여러 파일을 묶은 ZIP 파일 하나를 만들고, 다중 이미지 일괄 자르기도 PNG 여러 개를 ZIP으로 묶습니다.

ZIP 파일 이름에는 원본 파일 이름과 분할 수 또는 자르기 크기가 포함됩니다.

저장한 ZIP을 열면 무엇이 들어 있나요?

이미지 자르기와 GIF 분할의 ZIP에는 잘라낸 프레임 PNG들과 함께 애니메이션 미리보기용 HTML 파일, 배경 이미지 파일이 들어 있습니다. 이 HTML 파일을 더블클릭하면 재생 속도 슬라이더를 조절하며 애니메이션을 확인할 수 있습니다. 별도 인터넷 연결 없이 동작합니다.

다중 이미지 일괄 자르기의 ZIP에는 PNG 파일만 들어 있습니다. 자세한 내용은 ZIP과 index.html 미리보기로 애니메이션 확인에서 볼 수 있습니다.

프레임을 폴더별로 정리할 수 있나요?

가능합니다. 저장 전에 표시되는 미리보기 화면에서 폴더 정리를 켜면 사용할 폴더를 만들고 프레임을 나눠 담을 수 있습니다. 썸네일을 반초 정도 길게 누른 채 폴더로 끌어다 놓거나, 여러 개를 선택한 뒤 이동 버튼을 눌러 넣을 수 있습니다. 폴더를 삭제하면 그 안의 파일은 기본 위치로 되돌아오고, 남은 파일 번호는 연속으로 다시 매겨집니다.

GIF를 스프라이트 시트로 바꾸는 방법이 궁금합니다

GIF 스프라이트 분할 화면에서 GIF를 고르면 프레임 수와 길이가 표시되고 미리보기가 재생됩니다. 시트 레이아웃에서 가로 한 줄, 세로 한 줄, 격자 중 하나를 고른 뒤 스프라이트 시트 PNG, 프레임 PNG 모음 ZIP, GIF 다시 저장 중 원하는 형식으로 저장합니다. 투명 영역 자동 제거를 켜두면 모든 프레임에 공통으로 남는 투명 여백이 잘려 나옵니다.

자세한 방법은 GIF를 스프라이트 시트로 변환하기를 참고해 주세요.

문제가 생겼을 때

브라우저에서 열면 빈 화면이 나옵니다

이 도구는 JavaScript로 동작합니다. 브라우저 설정에서 JavaScript가 비활성화되어 있지 않은지 확인한 뒤 페이지를 새로고침해 주세요. 그래도 해결되지 않으면 다른 브라우저로 열어 보세요.

처리 중 화면이 멈춘 것처럼 보입니다

이미지가 크거나 만들어지는 프레임이 많으면 시간이 꽤 걸립니다. 다중 이미지 일괄 자르기는 진행률과 현재 파일 이름을 함께 표시하며, GIF 분할은 다시 계산되는 동안에도 조절 슬라이더를 움직일 수 있도록 표시됩니다. 브라우저 탭을 다른 탭으로 바꾸어도 처리는 계속됩니다.

해결되지 않는 문제가 있습니다

문의하기로 알려 주세요. 이 도구는 이용자의 이미지를 열람할 수 없으므로, 화면에 표시되는 오류 문구와 함께 브라우저 이름과 버전, 문제가 발생한 기능 이름을 적어 주시면 원인을 확인하기 훨씬 쉽습니다.
