■ 1. 프로젝트 개요
--------------------------------------------------------------------------------
- 이름       : spritescut (표시명: "AI 스프라이트 시트 분할 도구")
- 종류       : Flutter 데스크톱/모바일 앱 (Material 3)
- 역할       : 스프라이트 시트(이미지)를 업로드 → 균등 또는 수동 경계선으로
               프레임(컷) 단위 분할 → 배경 제거(크로마키) → ZIP 저장
- 특징 요약  :
  ・ 순수 Dart 기반 이미지 처리 (package:image, AI/신경망 미사용)
  ・ ZIP 저장 전 미리보기 다이얼로그에서 사진 삭제·사용자 폴더 분류 지원
  ・ 저장 ZIP에 index.html 애니메이션 미리보기와 stage.jpg 배경 포함
  ・ Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y) 실행 취소/다시 실행
- 버전       : 1.0.0+1 / Dart SDK ^3.12.2

■ 6. 최근 주요 변경 (폴더 정리 UX — 드래그 미동작 문제 해결)
--------------------------------------------------------------------------------
- 원인: LongPressDraggable은 kLongPressTimeout(0.5초) 이상 길게 눌러야 드래그가
  시작됨. 빠른 속성 드래그는 no-op (로직 버그가 아님, 테스트로 검증).
- 해결(사용자 선택안):
  ① 폴더 모드에서 삭제 오버레이 제거 — 선택은 파란 테두리+체크로만 표시
     (showDelete = !_folderMode && _marked.contains(index))
  ② 하단 [이동] 버튼 + '이동할 폴더 선택' 다이얼로그 추가 — 드래그 없이
     확실하게 이동 가능 (move-selected / move-target-*)
  ③ 힌트 문구 갱신: "이미지를 0.5초 길게 눌러 드래그하거나, 선택 후 [이동]
     버튼으로 넣으세요."
  ④ 폴더 생성 성공 시 스낵바 안내
  ⑤ [이동] 버튼은 폴더가 1개 이상일 때만, [선택 삭제]는 항상 표시
- 드래그 UX 자체(LongPressDraggable + DragTarget)는 유지 — 두 가지 방식 병행.

■ 8. 관찰 포인트 / 개선 후보 (참고용)
--------------------------------------------------------------------------------
- 파일명/폴더명 정제 로직이 SpriteCropper.sanitizeName과
  SavePreviewDialog._sanitizeFolderName에서 규칙이 조금 다르다(공백 처리).
  폴더명은 공백 유지(패턴에 \s 미포함), 파일명은 공백 제거 — 의도된 차이이나
  명시적으로 주석이 있으면 혼동 방지에 유리.
- SavePreviewDialog는 Dialog 위젯 내부에서 ScaffoldMessenger로 SnackBar를
  띄우는데, MaterialApp 하위라 동작하지만 테스트에서는 스낵바 타이머 정리가
  필요(createFolder 헬퍼에 4초 pump 추가됨).
- frameRects 오버라이드는 총 컷 수 변경 시 clearFrameRects로 초기화돼
  인덱스 불일치를 방지하고 있음.
- ImageCanvas.fitScale은 이미지를 "커짐 없이" 100% 피팅(scale ≤ 1)하므로
  해상도가 작은 시트는 작게 보일 수 있음 (의도된 1:1 표시).
- EditorScreen._saveZip에서 cropFrames로 얻은 프레임에 대해 다시
  img.decodeImage로 크기 재계산(sizes)을 수행 — 프레임 수×디코딩 비용.
- README.md와 pubspec.description은 기본 Flutter 템플릿 그대로(Boilerplate) —
  프로젝트 소개 문서화가 남은 숙제.
